Documentation

Everything you need to use PSZ.

PSZ is an encrypted project archive format with a matching unpacker.

project.psz

The encrypted project archive. Files are packed into TAR and encrypted using AES-256-GCM.

project.psz-data.lor

The matching unpacker containing the key required to decrypt the archive.

Installation

Install PSZ directly from GitHub: 

pip install git+https://github.com/SlabyLol/psz.git

Or clone the repository and install it: 

git clone https://github.com/SlabyLol/psz.git
cd psz
pip install -e .

Make

Create an encrypted project archive: 

psz make ./sample-project -o demo.psz

This produces: 

demo.psz
demo.psz-data.lor

Extract / Open

Extract an archive into an output directory: 

psz open demo.psz demo.psz-data.lor out/

You can also use the Python API: 

from pathlib import Path
from psz import open_archive

open_archive(
    Path("demo.psz"),
    Path("demo.psz-data.lor"),
    Path("out")
)

List archive contents 

psz list demo.psz demo.psz-data.lor

Python API 

from pathlib import Path
from psz import (
    create_archive,
    open_archive,
    list_archive_members
)

create_archive(
    Path("sample-project"),
    Path("demo.psz")
)

members = list_archive_members(
    Path("demo.psz"),
    Path("demo.psz-data.lor")
)

open_archive(
    Path("demo.psz"),
    Path("demo.psz-data.lor"),
    Path("out")
)

Unpacker languages

PSZ supports generated unpackers for:

  • Python
  • PHP
  • JavaScript / Node.js
  • HTML / Browser

PSZ format

PSZ archives begin with the PSZ1 magic value, followed by version 1, a 12-byte nonce and AES-256-GCM encrypted TAR data. 

PSZ1
VERSION = 1
NONCE = 12 bytes
CIPHERTEXT = encrypted TAR

Security

  • AES-256-GCM authenticated encryption
  • Random 256-bit key per archive
  • Random 12-byte nonce
  • Matching .psz-data.lor unpacker

Keep the matching .psz-data.lor private if the archive is sensitive.

Browser tools

The Make and Extract tools on this page run entirely in your browser. Files are not uploaded to a server by this page.

Extracting from the browser creates a ZIP download containing the decrypted project files.
