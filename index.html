PSZ

Encrypted project archives with a paired unpacker

AES-256-GCM · .psz + .psz-data.lor
GitHub Repository Test / Demo Repo

What is PSZ?

PSZ is a simple encrypted archive format made for projects. Every archive always consists of two files:

.psz

The encrypted archive (AES-256-GCM). Contains all your files packed as tar and then encrypted.

.psz-data.lor

The matching unpacker. Contains the key + code needed to open that specific .psz file.

You always need both files to extract the content.

Install

pip install git+https://github.com/SlabyLol/psz.git

Requires Python 3.9+

Create an archive

psz make ./my-project -o my-project.psz

Creates my-project.psz and my-project.psz-data.lor

Open / Extract an archive

Option 1 – using the psz tool

psz open my-project.psz my-project.psz-data.lor -o extracted/

Option 2 – run the .lor file directly

python my-project.psz-data.lor my-project.psz -o extracted/

The .lor file is a self-contained Python script that already knows the key.

Quick example

  1. Create 
    psz make ./dist -o release.psz
  2. Share both files (or keep the .lor private if the content is sensitive)
  3. Open later 
    psz open release.psz release.psz-data.lor -o out/

Docker

docker build -t psz .
docker run --rm -v $(pwd):/data psz make /data/myfolder -o /data/out.psz

GitHub Actions

Use PSZ in your CI to create encrypted artifacts. See the example workflow in the repository and the live demo in psz-test.

Security notes

  • Uses AES-256-GCM (authenticated encryption)
  • A new random key is generated for every archive
  • The key lives only inside the matching .lor file
  • Do not publish the .lor if the content should stay private
  • Path traversal protection is applied when extracting
